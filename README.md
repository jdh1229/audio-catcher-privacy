# Audio Catcher - Privacy Policy

This repository hosts the privacy policy for the Audio Catcher browser extension.

## 📄 Privacy Policy

View the privacy policy at: **https://jdh1229.github.io/audio-catcher-privacy/**

## 🔒 About

Audio Catcher is a browser extension that helps users detect and download audio files from web pages. This repository contains our privacy policy to ensure transparency about how we handle user data.

## 📌 Key Points

- We do **not** collect, store, or transmit any personal user data
- All processing happens locally in your browser
- No third-party analytics or tracking

## 📞 Contact

For questions about this privacy policy, please contact us through the Microsoft Edge Add-ons store listing.
