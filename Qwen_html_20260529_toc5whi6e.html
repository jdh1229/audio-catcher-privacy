Audio Catcher - Privacy Policy

Last updated: May 29, 2026

What data we collect

Audio Catcher does not collect, store, or transmit any personal user data. All audio detection and processing occurs entirely within the user's browser.

What permissions we use

  • sidePanel: To display the extension's user interface
  • activeTab: To detect audio elements on the current tab when activated by the user
  • downloads: To save detected audio files to the user's device
  • Host permissions: To detect audio content on any website the user visits

How we use website content

The extension reads webpage audio elements (<audio>, <video>, <source>) and monitors network requests solely to identify audio files available on the page. This data is processed locally and is never sent to any external server.

Third-party services

We do not use any third-party analytics, advertising, or data collection services.

Data sharing

We do not share any user data with third parties.

Data storage

The extension only uses local browser storage (chrome.storage.local) to save user preferences (e.g., enabled/disabled state). No browsing history, personal information, or audio files are stored or transmitted.

Contact

If you have questions about this privacy policy, please contact us through the Microsoft Edge Add-ons store listing.
